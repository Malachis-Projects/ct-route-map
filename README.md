# Connecticut Route Map

An interactive route optimization tool for Connecticut.

- All 169 towns outlined and selectable
- Address lookup with type-ahead, or paste a list of addresses
- Stop-order optimization (nearest neighbour, then 2-opt and or-opt) on real road drive times
- Trip planning: typical traffic by time of day, hourly weather at each stop, terrain climb, gas cost, best time to leave
- Option to stick to main roads

Data and services: US Census TIGER (town boundaries), OpenStreetMap, OSRM, Valhalla, Photon, Open-Meteo.
